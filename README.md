# Restaurant Management System — Software Engineering Design

## 📌 Project Overview

This repository presents selected coursework materials from a collaborative Software Engineering project completed at Middle East College, Oman.

The project focuses on analyzing and designing a proposed Restaurant Management System to support restaurant operations and order management.

**Project Type:** Academic Group Project  
**Module:** Software Engineering  
**Academic Year:** 2025

---

## 🎯 Project Objectives

The proposed system aims to:

- Improve restaurant order management.
- Reduce manual order processing errors.
- Support communication between restaurant staff.
- Improve the efficiency of restaurant operations.

---

This project covers:

- Software Development Life Cycle (SDLC)
- Agile Process Model
- Requirements Gathering
- Functional Requirements

- User Interface Prototyping

## 🖥️ UI Prototype

The order management prototype illustrates three screens:

**New Order Screen:** Allows restaurant staff to enter customer orders.

**Order Summary Screen:** Illustrates order details and confirmation.

**Kitchen Orders Screen:** Shows how kitchen staff could view incoming orders and their status.

The prototype is a conceptual design and does not represent a fully implemented application.
